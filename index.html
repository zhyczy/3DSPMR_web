Abstract

Embodied agents that answer questions about the physical world must see, remember, reason, and act. Existing MLLM-based embodied agents typically operate on short context windows of raw frames, which limits their ability to integrate information across long horizons of exploration. We introduce 3DSPMR, a framework that lifts streaming RGB(-D) observations into a persistent 3D spatial memory, on top of which a multimodal LLM performs sequential reasoning and decides where to look next. Our memory unifies geometry, object semantics, and uncertainty in a single structured representation, allowing the agent to retrieve evidence, plan exploration, and answer questions grounded in 3D rather than 2D pixels. Extensive experiments on embodied QA benchmarks show that 3DSPMR substantially improves answer accuracy and exploration efficiency over strong frame-stack baselines, and generalizes to unseen scenes and long-horizon questions.

Method — Vision to Geometry Pipeline

3DSPMR processes streaming RGB(-D) observations into a persistent 3D spatial memory that fuses geometry, object semantics, and uncertainty. At each step, the MLLM reads from the memory, decides where to look next, and emits answers grounded in 3D rather than in raw pixels.

1. Vision → Geometry

Per-frame RGB(-D) is lifted to metric-scale 3D point maps and registered into a globally consistent scene.

2. Spatial Memory

Structured object & region tokens are written into a persistent memory with geometry, semantics, and visit history.

3. MLLM Reasoning & Action

An MLLM reads from the memory to answer questions or to propose the next viewpoint for exploration.
